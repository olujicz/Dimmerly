Troubleshooting

Displays don’t dim

  • Dimmerly uses software dimming and screen blanking. To wake dimmed displays, move the mouse, press a key, or press Escape, depending on the wake setting in Settings › Displays.
  • Some displays and display modes do not respond equally to software gamma changes. Try changing brightness, warmth, or contrast separately to confirm which controls affect your display.

Brightness slider has no effect

Dimmerly changes brightness in software through the display’s gamma table. It does not change a monitor’s hardware backlight. Some displays, HDR modes, or color profiles may limit the visible effect.

Keyboard shortcut doesn’t work

Global keyboard shortcuts do not need Accessibility permission. Use at least two modifiers, including Control or Command, for example Control–Option–1. Choose a different shortcut in Settings › Shortcuts if the shortcut is unavailable or conflicts with another app.

A saved shortcut no longer works after updating to 1.3.0

Global shortcuts now require at least two modifiers, including Control or Command. Previously saved shortcuts that do not meet this rule are not registered. Reassign them in Settings; for example, use Control–Option–1 instead of Command–1 for a preset.

A per-display Shortcuts action stops working after updating from before 1.2.0

Dimmerly 1.2.0 changes how Shortcuts identifies displays. Existing shortcuts with a specific display selected need that display reselected once.

  1. Connect the display and open Dimmerly.
  2. Open the affected shortcut in the Shortcuts app.
  3. Select the display again in each affected Dimmerly action, then save the shortcut.
  4. Run the shortcut to confirm it controls the intended display.

A widget or Control Center action does not complete

Dimmerly opens when needed and waits for the app to acknowledge the action. If an error appears, open Dimmerly, check the selected preset still exists, and try again. On macOS 26 and later, add Dimmerly’s Dim Displays, Display Dimming, Auto Warmth, and Apply Preset controls in Control Center; Apply Preset asks you to choose a saved preset.

Menu bar icon not visible

  • If your menu bar is crowded, macOS may hide some icons. Try removing other menu bar items.
  • Quit and reopen Dimmerly from the Applications folder.

Frequently Asked Questions

Does Dimmerly work with built-in displays?

Yes. Dimmerly shows every connected display, including the built-in display, and dims each one in software.

How many presets can I save?

You can save up to 10 presets. Each preset can have its own keyboard shortcut.

Do sunrise and sunset schedules need my location?

No. Location access is optional and only used on your Mac to calculate sunrise and sunset. You can enter coordinates manually instead.

Does Dimmerly collect any data?

No. Dimmerly does not collect or transmit personal data, and it does not use analytics or tracking. Settings are stored locally on your Mac. If you choose “Use Current Location” for sunrise and sunset schedules, macOS Location Services may use Apple-provided location infrastructure. See the Privacy Policy.
