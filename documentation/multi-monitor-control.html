Control multiple monitors from one Mac menu bar panel

Dimmerly keeps each display’s brightness, warmth, contrast, presets, and supported hardware controls in one place, so a multi-monitor desk doesn’t require a trip through each monitor’s buttons.

Each display Independent brightness and color controls
Saved setups Presets for recurring work modes
Automation Schedules, widgets, and Shortcuts

Start with the display controls

  1. Install Dimmerly from GitHub Releases or with Homebrew.
  2. Connect your displays and open Dimmerly from the menu bar.
  3. Use the display rows to adjust brightness, warmth, and contrast independently.
  4. Expand a row to see extra controls when the display and build support them.

The direct-download build can also provide DDC/CI hardware controls for compatible external monitors. The App Store build has the software controls only.

Tune each display for the work in front of you

Use different brightness and warmth values for a built-in display, an external monitor, or a second screen across your desk. Each change applies only to the display you select.

For compatible external monitors in the direct-download build, DDC/CI can expose hardware brightness and additional controls such as contrast, volume, mute, or input source. When a display doesn’t support hardware control, Dimmerly uses software dimming for that display.

See the external monitors guide for DDC/CI setup and connection troubleshooting.

Save routines with presets and schedules

Presets save a complete display setup, including brightness, warmth, and contrast for each display. Apply them from the menu bar, a widget, Shortcuts, a schedule, or an optional per-preset keyboard shortcut.

On macOS 26 and later, add Display Dimming, Auto Warmth, and Apply Preset controls to Control Center or the menu bar. Choose a saved preset when configuring Apply Preset. The Display Dimming toggle reflects Dimmerly blanking, rather than macOS display sleep.

Starting with Dimmerly 1.2.0, you can find a saved preset by name in Spotlight. The Open Brightness Preset Shortcuts action opens it in the menu bar panel; use Apply Brightness Preset to apply its saved display settings. Individual menu bar display controls can also be targeted from Shortcuts and Spotlight on macOS 15.4 and later.

Schedules can run at a fixed time, sunrise, sunset, or with an offset from sunrise or sunset. You can use your current location for the calculation or enter coordinates manually.

Keep the setup local. Dimmerly stores presets and schedules on your Mac. The app doesn’t sync them between Macs and doesn’t use analytics or tracking.

Know the connection limitations

Multi-monitor control depends on how each display is connected. If the cable icon is missing after an external display’s name in the panel, common causes include:

  • DDC/CI is disabled in the monitor’s on-screen menu.
  • A USB-C hub, dock, KVM, HDMI adapter, or DisplayLink adapter isn’t passing DDC/CI commands.
  • The display exposes only some DDC/CI features, such as brightness but not input switching or volume.
  • The display connection or mode limits the effect of software gamma dimming.

For the most reliable hardware control, try connecting the monitor directly to the Mac over USB-C or DisplayPort. Without hardware control, Dimmerly still dims that display in software.

Set it up once

Install Dimmerly, make one preset for focused work and another for the evening, then switch between them from the menu bar, a widget, or a schedule.
