Troubleshooting

Brightness doesn’t change

  • Some displays, HDR modes, and color profiles respond less to software dimming. Change brightness, warmth, and contrast one at a time to see which of them affect the display.
  • App Store build: Dimmerly dims and blanks displays in software. To wake blanked displays, move the mouse, press a key, or press Escape, depending on your wake setting.
  • Direct-download build: on an external monitor, the slider sets the monitor’s own brightness over DDC/CI. If nothing happens, the commands aren’t reaching the monitor. The DDC/CI troubleshooting guide shows where they stop: the monitor’s own settings, docks and adapters, HDMI ports, or a monitor that stops answering until it’s unplugged.

Control Center’s Display Dimming toggle turns off again

The toggle shows whether Dimmerly is blanking a display. In the direct-download build’s Sleep & Lock mode, macOS puts displays to sleep and wakes them on input; the toggle returns to off because Dimmerly has no blanking session to clear. Choose Dim Only in Settings › Displays if you want the toggle to stay on while displays are blanked.

Menu bar icon not visible

  • The icon is a small sun, , near the clock. If you can’t find it, open Dimmerly again from the Applications folder or Spotlight. If it’s running but its icon is hidden, Dimmerly opens its Settings window instead, so you know it’s there.
  • On a MacBook with a notch, icons that don’t fit beside the notch are hidden. Hold ⌘ and drag Dimmerly’s icon closer to the clock, so other icons are hidden first, or quit apps you don’t need in the menu bar. A menu bar manager such as Bartender or Ice can also make room.
  • On macOS 26 and later, open System Settings › Menu Bar and check that Dimmerly is allowed in the menu bar.
  • If the icon is gone after you restart your Mac, Dimmerly isn’t opening at login. Turn on Launch at login in Settings › General.

Keyboard shortcut doesn’t work

App Store build: global keyboard shortcuts don’t need Accessibility permission. Use at least two modifiers, including Control or Command. If the shortcut is unavailable or conflicts with another app, choose a different one in Settings › Shortcuts.

Direct-download build:

  1. Open System Settings › Privacy & Security › Accessibility.
  2. Make sure Dimmerly is listed and enabled.
  3. Shortcuts start working as soon as access is granted. You don’t need to restart Dimmerly.
  4. If the shortcut still doesn’t work, try changing it in Settings › Shortcuts to avoid conflicts with other apps.

Widget or Control Center action doesn’t complete

Dimmerly opens when needed and waits for the app to acknowledge the action. If an error appears, open Dimmerly, check the selected preset still exists, and try again. On macOS 26 and later, add Dimmerly’s Dim Displays, Display Dimming, Auto Warmth, and Apply Preset controls in Control Center; Apply Preset asks you to choose a saved preset.

Frequently asked questions

Does Dimmerly work with built-in displays?

Dimmerly shows connected displays, including the built-in display where supported. The App Store build uses software dimming. The direct-download build may use additional hardware brightness controls where macOS and the display support them.

How many presets can I save?

You can save up to 10 presets. Each preset can have its own keyboard shortcut.

Does the Dimmerly app collect any data?

No. The Dimmerly app does not collect or transmit personal data, and it does not use analytics or tracking. The app does not send data to developer-operated servers. Settings are stored locally on your Mac. From version 1.5.0, the direct-download build can check GitHub for updates if you allow it; the check sends no system profile. This website uses privacy-focused, aggregated Cloudflare Web Analytics. If you choose “Use Current Location” for sunrise/sunset schedules, macOS Location Services may use Apple-provided location infrastructure. See the privacy policy.

How do I update Dimmerly?

The App Store build updates through the App Store. From version 1.5.0, the direct-download build updates itself: choose Check for Updates… in Settings > About or in the menu bar icon’s right-click menu, or let it check automatically. It asks before checking automatically. If you installed it with Homebrew, the in-app updater works too, and so does a plain brew upgrade. Avoid brew upgrade --greedy for Dimmerly: it can put back an older version than the one the app already updated itself to.

What’s the difference between the App Store and direct-download builds?

The App Store build runs in Apple’s sandbox, so it dims and blanks displays in software. The direct-download build can put displays to sleep using macOS system commands and includes DDC/CI hardware monitor control features when supported by your display and connection. The external monitors guide compares the two builds side by side.

Remove Dimmerly

  1. Open the panel and choose Quit Dimmerly, or press ⌘Q while the panel is open.
  2. Drag Dimmerly from the Applications folder to the Trash. If you installed it with Homebrew, run brew uninstall --zap --cask dimmerly instead, which also deletes its settings.
  3. Without Homebrew, presets and settings stay on your Mac until you delete them: ~/Library/Preferences/rs.in.olujic.dimmerly.plist, and the folders whose names contain rs.in.olujic.dimmerly in ~/Library/Containers and ~/Library/Group Containers.
