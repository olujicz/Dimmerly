Dimmerly Support

Per-display brightness, warmth, presets, and external monitor controls from the menu bar.

Which build do you have? If you downloaded Dimmerly from GitHub or installed it with Homebrew, you have the direct-download build. If you installed it from the Mac App Store, you have the App Store build. Only the direct-download build has a Hardware Control section in Settings › Displays. Where the answers below differ, they say which build they cover.

Troubleshooting

Displays don’t dim

  • The App Store build uses software dimming and screen blanking. To wake dimmed displays, move the mouse, press a key, or press Escape, depending on your wake setting.
  • Some displays and display modes do not respond equally to software gamma changes. Try changing brightness, warmth, or contrast separately to confirm which controls affect your display.
  • In the direct-download build with DDC/CI enabled, check that your external display supports DDC/CI brightness control, and try connecting it directly to your Mac.
  • If a monitor that supports DDC/CI stops responding, unplug it from mains power for one to two minutes and reconnect it. The monitor’s DDC/CI controller can lock up while the picture keeps working, and a standby press or an on-screen-menu reset does not clear it. Dimmerly re-probes the display automatically.
  • Run only one DDC/CI tool at a time. Two apps talking to the same monitor interleave each other’s replies and can make a working monitor look broken.
  • Many USB-C to HDMI cables and adapters have a built-in converter chip that passes the picture but drops DDC/CI entirely. If hardware controls never appear through one, use a USB-C to DisplayPort cable or the Mac’s HDMI port instead.

Keyboard shortcut doesn’t work

In the App Store build, global keyboard shortcuts do not need Accessibility permission. Use at least two modifiers, including Control or Command. Choose a different shortcut in Settings › Shortcuts if the shortcut is unavailable or conflicts with another app.

For the direct-download build:

  1. Open System Settings › Privacy & Security › Accessibility.
  2. Make sure Dimmerly is listed and enabled.
  3. Shortcuts start working as soon as access is granted. You don’t need to restart Dimmerly.
  4. If the shortcut still doesn’t work, try changing it in Settings › Shortcuts to avoid conflicts with other apps.

Control Center’s Display Dimming toggle turns off again

The toggle shows whether Dimmerly is blanking a display. In the direct-download build’s Sleep & Lock mode, macOS puts displays to sleep and wakes them on input; the toggle returns to off because Dimmerly has no blanking session to clear. Choose Dim Only in Settings › Displays if you want the toggle to stay on while displays are blanked.

A widget or Control Center action does not complete

Dimmerly opens when needed and waits for the app to acknowledge the action. If an error appears, open Dimmerly, check the selected preset still exists, and try again. On macOS 26 and later, add Dimmerly’s Dim Displays, Display Dimming, Auto Warmth, and Apply Preset controls in Control Center; Apply Preset asks you to choose a saved preset.

Brightness slider has no effect

  • The App Store build uses software brightness through gamma tables. Some displays, HDR modes, or color profiles may limit the visible effect.
  • The direct-download build can use DDC/CI hardware brightness for supported external monitors. Some USB-C hubs, docks, DisplayLink adapters, TVs, or monitor settings may block DDC/CI.

Menu bar icon not visible

  • If your menu bar is crowded, macOS may hide some icons. Try removing other menu bar items or using a tool like Bartender.
  • Restart Dimmerly from Applications.

Frequently Asked Questions

Does Dimmerly work with built-in displays?

Dimmerly shows connected displays, including the built-in display where supported. The App Store build uses software dimming. The direct-download build may use additional hardware brightness controls where macOS and the display support them.

How many presets can I save?

You can save up to 10 presets. Each preset can have its own keyboard shortcut.

Does the Dimmerly app collect any data?

No. The Dimmerly app does not collect or transmit personal data, and it does not use analytics or tracking. The app does not send data to developer-operated servers. Settings are stored locally on your Mac. This website uses privacy-focused, aggregated Cloudflare Web Analytics. If you choose “Use Current Location” for sunrise/sunset schedules, macOS Location Services may use Apple-provided location infrastructure. See our Privacy Policy.

What’s the difference between the App Store and direct-download builds?

The App Store build runs in Apple’s sandbox and dims and screen-blanks displays using gamma tables. The direct-download build can put displays to sleep using macOS system commands and includes DDC/CI hardware monitor control features when supported by your display and connection. Feature differences are documented in the README and release notes.
