Dimmerly for macOS

Every display on your Mac, tuned from the menu bar.

Dimmerly puts per-display brightness, warmth, contrast, and external monitor hardware controls in the macOS menu bar. Save presets and schedules, with software dimming when hardware control is unavailable.

Download for macOS Requires macOS 15 Sequoia or later

Install with Homebrew.

This installs the direct build, which includes the DDC/CI hardware controls.

brew tap olujicz/dimmerly
brew install --cask dimmerly

Built for multi-display Macs.

Direct controls for the parts of a display setup that macOS and monitor buttons leave scattered.
