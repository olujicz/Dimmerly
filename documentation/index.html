Every display on your Mac, tuned from the menu bar.

Dimmerly is a free, open-source app that puts per-display brightness, warmth, contrast, and external monitor hardware controls in the macOS menu bar. Save presets and schedules. Where a monitor can’t take hardware control, Dimmerly dims it in software.

The display controls macOS leaves out.

Night Shift warms every screen at once, and most external monitors hide their brightness behind their own buttons. Dimmerly puts each display within reach of the menu bar.

Control each display separately

Adjust brightness, warmth, and contrast without changing every screen at once.

Use the monitor’s hardware controls

Through DDC/CI, the control channel in the display cable, Dimmerly sets the monitor’s own brightness, contrast, volume, mute, and input where the display supports them.

Save complete display setups

Recall presets instead of rebuilding the same brightness and warmth settings by hand.

Automate the routine

Use schedules, global shortcuts, desktop widgets, Shortcuts actions, and Control Center controls.

Set up the way your displays behave.

Choose display sleep or dim-only mode, set an inactivity timer, and tune automatic warmth in one native Settings window.

Further down the same pane, Hardware Control lists what each external monitor accepts over DDC/CI. A monitor that doesn’t answer is dimmed in software instead, so brightness, warmth, and presets still work on it.

Get Dimmerly.

Free, signed, and notarized. Includes hardware brightness for monitors that support DDC/CI; any other display is dimmed in software.

A direct DisplayPort or USB-C cable is the most reliable path. Docks, hubs, and USB-C to HDMI adapters often drop the commands; check your connection.

After you download

  1. Drag Dimmerly to Applications. Open the DMG, drag the app into the Applications folder, and open it from there. The first time, macOS asks whether to open an app downloaded from the Internet; choose Open.
  2. Find it in the menu bar. Dimmerly has no window or Dock icon. Click near the clock to open the panel. Can’t see it?
  3. Allow access only if you want it. Global shortcuts need Accessibility permission, and sunrise and sunset schedules use your location unless you enter coordinates. The panel, presets, and hardware controls need neither.

Updates. Dimmerly doesn’t check for updates itself. With Homebrew, run brew upgrade --cask dimmerly. Otherwise, get the new DMG from Releases and replace the app.
