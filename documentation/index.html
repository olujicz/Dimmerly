Dimmerly for macOS

Every display on your Mac, tuned from the menu bar.

Dimmerly is a free, open-source app that puts per-display brightness, warmth, contrast, and external monitor hardware controls in the macOS menu bar. Save presets and schedules, with software dimming when hardware control is unavailable.

Download for macOS Requires macOS 15 Sequoia or later

Built for multi-display Macs.

Direct controls for the parts of a display setup that macOS and monitor buttons leave scattered.

01

Control each display separately

Adjust brightness, warmth, and contrast without changing every screen at once.

02

Use the monitor’s hardware controls

Through DDC/CI, the control channel in the display cable, Dimmerly sets the monitor’s own brightness, contrast, volume, mute, and input where the display supports them.

03

Save complete display setups

Recall presets instead of rebuilding the same brightness and warmth settings by hand.

04

Automate the routine

Use schedules, global shortcuts, desktop widgets, Shortcuts actions, and Control Center controls.

Set up the way your displays behave.

Choose display sleep or dim-only mode, set an inactivity timer, and tune automatic warmth in one native Settings window.

Hardware controls work where your display and connection support DDC/CI. Otherwise, Dimmerly falls back to software brightness, as shown here.
