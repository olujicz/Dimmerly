Every display on your Mac, tuned from the menu bar.

Dimmerly is a free, open-source menu bar app that sets the brightness, warmth, and contrast of each display on your Mac, and turns down an external monitor’s own backlight where the monitor allows it. Save presets and schedules.

The display controls macOS leaves out.

Night Shift warms every screen at once, and most external monitors hide their brightness behind their own buttons. Dimmerly puts each display within reach of the menu bar.

Turn down the monitor itself

Hardware control sets the monitor’s own brightness, contrast, volume, mute, and input over DDC/CI, the control channel in the display cable. A direct DisplayPort or USB-C cable works best. A monitor that doesn’t answer is dimmed in software, so presets and schedules still cover it.

Version 1.4.2, released 5 November 2026. What’s new

Install with Homebrew 
brew tap olujicz/dimmerly
brew install --cask dimmerly

Updates are manual: run brew upgrade --cask dimmerly, or download the new DMG from Releases and replace the app.

After you download

  1. Drag Dimmerly to Applications. Open it from there. The first time, macOS asks whether to open an app from the Internet; choose Open.
  2. Find it in the menu bar. Dimmerly has no window or Dock icon. Click near the clock to open the panel. Can’t see it?
  3. Allow access only if you want it. Global shortcuts need Accessibility permission, and sunrise and sunset schedules use your location unless you enter coordinates. The panel, presets, and hardware control need neither.

The app has no analytics, tracking, ads, or app-managed network requests. This website uses privacy-focused, aggregated Cloudflare Web Analytics. Privacy policy
