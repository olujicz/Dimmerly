External monitor brightness not working on your Mac?

Mac apps change an external monitor’s backlight over DDC/CI, a control channel that runs inside the video cable. When the brightness slider does nothing, or only darkens the picture, something between the Mac and the monitor is dropping those commands. Work through the checks below in order.

Most common cause A dock, hub, KVM, or adapter in the path
Worked before, stopped now Unplug the monitor from power for a minute
Nothing helps Software dimming still works

1. See what Dimmerly found

Open Dimmerly from the menu bar. A display under hardware control shows a small cable icon next to its name. No icon means Dimmerly is dimming that display in software, which darkens the picture but leaves the backlight as it was.

For the reason, open Settings › Displays and look at the Hardware Control section. Each monitor gets a status line, with the same icon as in the app:

Status What it means
Hardware controls: Brightness, Contrast… DDC/CI works. The list shows what this monitor accepts.
Hardware brightness unavailable The monitor answers but won’t take brightness commands. Other listed controls still work.
No DDC/CI reply. Unplug the monitor from power for a minute. The commands reach the monitor, but its DDC/CI controller doesn’t answer. Go to step 4.
Uses software brightness The commands never reach the monitor. Start with steps 2 and 3.

If the section is missing, you have the App Store build. It runs in Apple’s sandbox, which doesn’t allow DDC/CI. Install the direct-download build from GitHub or with Homebrew instead. If Use hardware controls when available is off, turn it on.

2. Check the monitor

  1. Open the monitor’s on-screen menu with its own buttons and look for a DDC/CI setting, usually in a system or setup menu. Turn it on.
  2. Some monitors don’t support DDC/CI at all, and many TVs don’t either. Others accept brightness but not contrast, volume, or input switching.
  3. Quit any other app that talks to the monitor, such as MonitorControl, Lunar, BetterDisplay, or a command-line tool like m1ddc. Two apps on the same monitor interleave each other’s replies, and a working monitor can look broken.

3. Check everything between the Mac and the monitor

Most failures happen here. The picture can come through fine while the DDC/CI commands get lost on the way.

  • Docks, hubs, and KVM switches often pass video but not DDC/CI. Connect the monitor straight to the Mac to test.
  • USB-C to HDMI cables and adapters usually contain a converter chip. Many of those chips pass the picture and drop DDC/CI. A USB-C to DisplayPort cable avoids the conversion.
  • DisplayLink adapters send video over USB through their own driver and can block DDC/CI completely.
  • The built-in HDMI port on some Macs, including M1 models and the entry-level M2 Mac mini, routes DDC/CI through a converter chip and is less reliable than USB-C. If HDMI doesn’t work, try USB-C or Thunderbolt to DisplayPort.

The most reliable path is a single cable from a USB-C or Thunderbolt port on the Mac to the monitor’s DisplayPort or USB-C input. Dimmerly checks each monitor again when it’s plugged in, so you can swap cables without restarting the app.

4. Worked yesterday, silent today

A monitor’s DDC/CI controller can lock up while the picture keeps working. Swapping cables, changing inputs, and resetting the on-screen menu won’t revive it, and neither will the power button, because standby keeps the controller running.

  1. Unplug the monitor’s power cable from the wall or the monitor.
  2. Wait one to two minutes.
  3. Plug it back in and turn it on.

Dimmerly checks the monitor again on its own and shows the cable icon once it answers.

If hardware control still won’t work

Dimmerly keeps working without DDC/CI. It dims the display in software through macOS gamma tables, and warmth, contrast, presets, schedules, and shortcuts behave the same. The picture gets darker, but the backlight stays at the level set on the monitor, so lowering the monitor’s own brightness once and dimming the rest in software is a reasonable setup.
