Control external monitor brightness on macOS

macOS doesn’t expose every third-party monitor’s brightness controls in one place. Dimmerly puts per-display brightness, warmth, contrast, and supported monitor controls in the menu bar.

Hardware control DDC/CI on supported displays
Fallback Software dimming through macOS
Best starting point Direct download or Homebrew

How hardware monitor control works

The direct-download build talks to compatible external monitors over DDC/CI. When the display and connection support it, Dimmerly changes the monitor’s hardware brightness and adds controls such as contrast, volume, mute, or input source.

Install the signed and notarized build from GitHub Releases, or install it with Homebrew:

brew tap olujicz/dimmerly
brew install --cask dimmerly

After connecting the monitor, open Dimmerly from the menu bar. A small cable icon after the monitor’s name means Dimmerly is controlling it over DDC/CI.

When Dimmerly uses software dimming

Software dimming changes the image sent to the display through macOS’s gamma tables. It changes perceived brightness, but it doesn’t change the monitor’s physical backlight. This fallback is useful for built-in displays and external monitors that don’t expose usable DDC/CI controls.

The direct-download build can fall back to software dimming for a display when hardware control is unavailable. The App Store build runs in Apple’s sandbox, so it uses software controls only and has no DDC/CI hardware control.

Direct download or App Store build?

Both builds provide the everyday display controls. Choose the direct-download build when external-monitor hardware control or display sleep is important.

Capability Direct-download build App Store build
Brightness, warmth, and contrast Yes Yes
DDC/CI hardware monitor control Supported displays and connections No
Display sleep using macOS system tools Yes No
App Sandbox No Yes

If the cable icon doesn’t appear

A monitor can support DDC/CI while the dock or adapter between it and the Mac doesn’t pass the commands through, so the same display may work on a direct cable and not through a dock. The DDC/CI troubleshooting guide checks the monitor setting, docks and adapters, HDMI ports, and monitors that stop answering. If none of it helps, open a monitor compatibility issue with your display model and connection type.
