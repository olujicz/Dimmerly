# Korean · ko

Use formal polite **합니다체** in complete sentences and prompts. The existing status text uses **습니다**, so use **하십시오** for requests and **습니까** for questions. Use short noun or action phrases for labels.

Write Hangul with Korean word spacing and use “…” in new prose. Use **디스플레이** for display, **밝기** for brightness, **프리셋** for a preset and **단축키** for a shortcut. Rephrase around substitutions if an attached particle depends on the final sound of an unknown name.

**색온도** is the established short label for color temperature. Check the available rendered width and wrapping.
