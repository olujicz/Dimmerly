# French · fr

Use **vous** for instructions and infinitives for action labels. This follows the location, shortcut and wake strings. Use Latin script, French accents, curly apostrophes and « … ». Use a narrow no-break space (U+202F) inside the quotation marks and before `; ! ? :` throughout, including existing strings.

Use **écran** for display, **luminosité** for brightness, **préréglage** for a preset and **raccourci** for a shortcut. Use **position** for the user's current position and **emplacement** for a place selected in settings.

Several French labels and the timer's **minute/minutes** forms share English spelling. The longer **Activer/désactiver l’assombrissement** label describes both actions. Check its width in the shortcut and control surfaces.

## Decisions

- Address: **vous**, or infinitives; do not use `tu`.
- Buttons and menu items: infinitive (`Réessayer`, `Appliquer`, `Supprimer`).
- Gender: no gendered forms address the user; use épicène wording or the infinitive.
- Typography: « … » with narrow no-break spaces (U+202F), narrow no-break space before `; ! ?` and `:`; curly apostrophes.
