# Serbian Latin · sr

Use informal singular **ti** throughout the app, widget and permission prompts. This follows the predominant forms in action labels, error recovery and shortcut instructions. Use singular imperatives such as **izaberi**, **pritisni** and **unesi**. Use **tvoj** and its inflections when possession matters.

Write Serbian Latin with ekavian forms, all diacritics and „…“ quotation marks. Use **ekran** and its inflections for display, **monitor** for physical hardware, **osvetljenost** for brightness, **podešavanje** for a preset and **prečica** for a shortcut. Use **vidžet** in UI copy. Cover **one**, **few** and **other** in cardinal plurals. Use **sr** with the checker because that is the catalog tag.
