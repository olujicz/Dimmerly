# Brazilian Portuguese · pt-BR

Use **você** when a pronoun is needed and use **seu/sua** for possession. The existing location and wake instructions use this register. Use Brazilian vocabulary, Latin script with Portuguese diacritics and “…” in new prose.

Use **tela** for display in general, **monitor** for physical controls, **brilho** for brightness, **predefinição** for a preset and **atalho** for a shortcut. Geographic labels such as **Latitude** and **Longitude** and technical terms such as **Hardware** and **Software** may match English.

## Decisions

- Address: **você** (omitted where possible), **seu/sua**; do not use `tu`.
- Buttons and menu items: infinitive (`Aplicar`, `Excluir`, `Tentar novamente`).
- Gender: no gendered forms address the user; use impersonal or infinitive wording.
- Typography: “…”, Brazilian spelling and vocabulary.
