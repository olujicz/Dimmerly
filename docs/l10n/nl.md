# Dutch · nl

Use informal singular **je**, following the existing location and input-switching prompts. Use Latin script, Dutch compound spelling and ‘…’ in new prose.

Use **scherm** for display and **monitor** for physical controls. Use **helderheid** for brightness, **voorinstelling** for a preset and **sneltoets** for a shortcut. Place the display name after **Contrast van** and **Volume van** in accessibility labels. Retain standard input labels and established terms such as **Contrast**, **Trigger**, **Warm** and **Updates**. The checker also reports the stale **Dim** label.

## Decisions

- Address: informal **je**; do not use `u`.
- Buttons and menu items: single-word actions use the imperative, matching macOS Dutch (`Annuleer`, `Voeg toe`, `Verwijder`, `Werk bij`, `Schakel over`, `Pas toe`, `Probeer opnieuw`). Multi-word actions and messages use the infinitive (`Schema toevoegen…`, `Handmatig invoeren…`).
- Gender: no gendered forms address the user.
- Typography: ‘…’ in new prose; compounds written solid.
